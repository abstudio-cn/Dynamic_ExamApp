# 框架化答题系统

> 通用框架式在线答题平台 — 支持自定义题目类型、灵活扩展题库、附带完整使用说明书

## 设计理念

本系统采用**框架化**架构设计，不局限于特定考试或题型。你可以：

- ➕ **自行增加题目类型** — 修改 `Question.cs` 枚举 + `MdParserService.cs` 解析规则即可扩展
- ✏️ **自行修改题型判断逻辑** — 所有题型识别集中在 `DetermineType()` 方法，一站式定制
- 📦 **题库零耦合** — 按 `类别/任意名称.md` 组织，增删文件即时生效，无需改代码
- 📖 **附带说明书** — 本文档即完整使用手册，涵盖安装、配置、扩展、故障排查

## 功能特性

### 答题引擎
- 📝 **4种内置题型**：单选题、多选题、判断题、案例分析（简答题）
- 🎯 **智能抽题**：多类别混合 + 按题型比例均分 + 随机乱序
- ⏱ **倒计时/正计时**：可配置时长（15~120分钟），归零自动提交
- 📊 **成绩报告**：正确率、答题详情、正确答案和解析
- 🤖 **AI评分**：案例分析题通过 DeepSeek API 自动评分（网页端可配置API Key）

### 安全机制
- 🔒 **Canvas防篡改**：分数用Canvas渲染为图片，DOM中无文字节点可改
- 🔄 **服务端验证**：提交后每5秒轮询服务端数据，自动覆盖篡改
- 🛡️ **MD安全渲染**：Markdown→HTML 白名单标签 + 编码，防XSS注入

### 管理功能
- ⚙️ **网页端API设置**：直接在界面上配置AI接口地址和密钥，代码无硬编码
- 🏷️ **动态标题**：从 `题库/题库类型.md` 读取系统名称和副标题

## 自定义题目类型（框架扩展）

### 新增一种题型只需3步

**第1步：定义类型**

编辑 `Models/Question.cs`，在 `QuestionType` 枚举中添加：
```csharp
public enum QuestionType
{
    SingleChoice,
    MultiChoice,
    TrueFalse,
    CaseAnalysis,
    // 👇 在此添加你自己的类型
    FillInBlank,      // 填空题
    SortOrder,        // 排序题
    Matching,         // 配对题
}
```

**第2步：添加识别规则**

编辑 `Services/MdParserService.cs` 的 `DetermineType()` 方法：
```csharp
// 示例：识别填空题
if (block.Contains("【填空题】") || block.Contains("____"))
    return QuestionType.FillInBlank;
```

**第3步：新增答案比对逻辑**

编辑 `Controllers/ExamController.cs` 的 `CompareAnswers()` 方法：
```csharp
if (type == QuestionType.FillInBlank)
{
    // 填空题：忽略空白字符、大小写
    return cleanCorrect.Replace(" ", "").Replace("\n", "")
        == cleanUser.Replace(" ", "").Replace("\n", "");
}
```

### 调整题型判断优先级

所有题型识别集中在 `MdParserService.DetermineType()` 一个方法中。执行顺序即为优先级：

```
标签检测 → 模式检测 → 答案格式检测 → 选项数量检测 → 复杂答案回退 → 兜底
```

调整 `if` 块的顺序即可改变优先级。例如，想让填空题优先于单选题识别，把填空题的检测代码移到最前面。

### 题型解析全流程

```
Markdown文件
  ↓ SplitQuestions()    根据 **N.** 分割题目块
  ↓ DetermineType()     判断题型（标签/模式/答案/选项）
  ↓ ExtractAnswer()     提取答案（支持多行、内联）
  ↓ ExtractContent()    分离题干与选项
  ↓ MarkdownSafeRenderer  MD→安全HTML（白名单 + 编码）
  ↓ Question 对象       存入 QuestionBankService 内存缓存
```

## 制作题目

> 💡 **无需手写格式** — 将 `题目生成策略.md` 交给 AI（如 ChatGPT、DeepSeek 等），告诉它你要生成什么类型、多少道题，AI 会按标准格式自动输出。把输出内容保存为 `.md` 文件放入对应类别目录即可使用。

详见项目根目录的 `题目生成策略.md`，包含完整的格式规范、解析器识别条件和示例。

### 格式速览（开箱即用）

```markdown
**1.** 建筑工程安全生产管理条例规定，施工现场安全由谁负责？
A. 建设单位 B. 施工单位 C. 监理单位 D. 设计单位
**答案: B**
**难度: 基础**
**解析: 条例明确规定施工单位对施工现场安全负总责，建设单位负首要责任不替代施工安全责任。**
```

### 判断题
```markdown
**1.** 建筑业企业资质分为施工总承包、专业承包和劳务分包三个序列。
A. 对 B. 错
**答案: 对**
```

### 案例分析题（两种格式均支持）

**格式A — 考试酷真题格式：**
```markdown
**33.** 某市进行市政工程招标，招标范围限定为本省大型国有企业...
【问题】
1.建设单位对投标单位的限定是否合法？说明理由。
2.商务标编制存在不妥当之处，请予以改正。
**答案: 1.(本小题3分)...**
```

**格式B — 自创题库格式：**
```markdown
**1.** 【案例分析】某工程基坑开挖深度8m，周边建筑物密集...
**问题：**
(1) 基坑支护方案应包含哪些内容？
(2) 地下水处理应注意什么？
**答案:**
(1) 支护方案应包含...
(2) 地下水处理应...
**难度: 提高**
```

### 扩展格式（自定义题型示例）

```markdown
**1.** 【填空题】建设工程项目总进度目标论证的工作步骤包括：____、____、____。
**答案: 调查研究和收集资料、进度计划系统的结构分析、项目的工作编码**
```

> 📄 完整格式规范、边界条件、常见问题解决，见项目根目录 `题目生成策略.md`。

## 题库管理

### 用 AI 生成题目

1. 将 `题目生成策略.md` 发给 AI（ChatGPT / DeepSeek / Claude 等）
2. 告诉 AI 你的需求：`请按照这个策略文件，帮我生成50道一级建造师《建设工程法规》的单选题，难度中等`
3. AI 输出的内容保存为 `.md` 文件，放入对应类别目录
4. 重启服务即可

### 添加新题库

```
题库/
├── 目录/          ← 类别 = 目录名
│   ├── 2024年真题.md       ← 任意文件名，自动加载
│   ├── 模拟卷1.md
│   └── 自创题库.md
├── 目录2/
│   └── ...
└── 题库类型.md            ← 系统标题/副标题（可选）
```

- 新增类别：在 `题库/` 下新建文件夹
- 新增题目：在类别目录下新建 `.md` 文件，重启服务即可（`启动答题系统.bat` 一键重启）
- 删除题目：删除对应 `.md` 文件即可

### 格式检测优先级

系统按以下顺序识别题型，靠前的优先匹配：

| 优先级 | 检测方式 | 命中条件 |
|--------|----------|----------|
| 1 | 标签 | 含 `【案例分析】`、`【简答】`、`【案例` |
| 2 | 模式 | 含 `【问题】`、`**问题**`、`**背景**`、`**案例**` |
| 3 | 答案 | 答案 = 对/错/√/× → 判断题 |
| 4 | 答案 | 答案 = A-E多字母 → 多选题 |
| 5 | 答案 | 答案 = A-E单字母 → 单选题 |
| 6 | 答案 | 多行中文/编号①②③/长度>10 → 案例分析 |
| 7 | 选项数 | 5+ → 多选题 |
| 8 | 选项数 | 2-4 → 单选题 |
| 9 | 回退 | 无选项+长文本 → 案例分析 |

## API接口

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/exam/categories` | GET | 所有类别及题型统计 |
| `/api/exam/questions` | POST | 按类别/题型抽取题目 |
| `/api/exam/submit` | POST | 提交答案 → 自动评分 |
| `/api/exam/result/{id}` | GET | 查询结果（防篡改验证） |
| `/api/exam/settings` | GET/POST | 读取/保存AI配置 |
| `/api/exam/settings/verify` | POST | 测试AI连接 |
| `/api/exam/config` | GET | 系统标题/副标题 |

## 常见问题

**Q: 添加了新题型但前端不显示？**
需要在 `wwwroot/js/app.js` 中找到题型映射代码，添加新类型的渲染模板。

**Q: 案例分析题被误判为单选题？**
检查 MD 文件是否有 `【案例】` 或 `【问题】` 标记。无标记时，确保答案长度 > 10 且含中文，系统会自动回退识别。（v2026-07-26 已修复此问题）

**Q: 如何批量导入题目？**
只需复制 `.md` 文件到对应类别目录，重启服务即可。文件命名为 `任意名称.md`，系统自动解析。

**Q: AI评分不工作？**
在答题系统网页的「设置」页配置 DeepSeek API 地址和密钥，点击「验证连接」测试。
